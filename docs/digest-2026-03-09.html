📑 Hacer que la FID de reconstrucción sea predictiva de la FID de generación de difusión
Se conoce que la FID de reconstrucción (rFID) de un modelo de variación autoencodradora (VAE) tiene una pobre correlación con la FID de generación (gFID) de un modelo de difusión latente. Se propone una variante sencilla de rFID llamada FID interpolada (iFID), que muestra una fuerte correlación con gFID. iFID se logra interpolando las representaciones latentes de cada elemento del conjunto de datos y sus vecinos más cercanos en el espacio latente. De esta forma, se calcula la FID entre las muestras decodificadas y las originales.
